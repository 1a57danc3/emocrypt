## 修复 npm run build 报错
- 报错 `[BUILD_UTILS_SPAWN_1] Command "npm run build" exited with 1` 的根因：package.json 的 build 脚本末尾多了一句 `npm build --output public`，而 npm 没有 `build` 子命令（只有 `npm run build`），导致 `Unknown command: "build"` 退出 1。test/tsc/bundle 三步其实都成功了。
- 已把 build 脚本恢复为 `npm run test && tsc && npm run bundle`，重新构建 EXIT=0，build/ 下生成 emocrypt.js / bundle.js / emocrypt.min.js（含新 1170 emoji）。
- 备注：`npm build --output public` 看起来是想把产物输出到 public/（用于部署），但写法非法；若真需要 public 输出，应换成正确的复制步骤。
